### Chrome Dev tools handy things

- cmd + p = search for a specific file
- cmd + shift + p = Chrome Tools Command Palette
- Right click on a segment in the elements tab and press capture node screenshot
- cmd + shift + p and search for capture full size screenshot
- Right click on the refresh icon for the page when dev tools is open to see different reload options
- Right click a console message and press copy console message
- More tools > animations tab (useful to reverse engineer animations)
